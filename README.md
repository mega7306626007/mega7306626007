### ⚡ Who I am in 15 seconds

I'm **Emmanuel** — an engineering student turned builder working at the intersection most people keep separate:

> **Electrical Engineering** gives me systems thinking. **Software** gives me a way to build them. **AI** gives me a way to make them adaptive.

I don't do tutorial clones. I build **real systems**: finance that understands student life, French that speaks Sheng, transcription that hears Kiswahili, news pipelines that run themselves, poetry that thinks with neural nets.

**My signature:** offline-first, context-aware, African-grounded, world-ready.

```text
Raw data  →  Structured understanding  →  Personal context
     →  Pattern recognition  →  Reasoning  →  Adaptive response
```

This one pipeline runs through *everything* I build — from chatbots to finance to language learning.

### 🧬 How I build

**1. Context before code.** Who is this for? What constraints (offline, low-data, Sheng-speaking) shape it?
**2. Local-first.** If it needs a server to be useful, it's fragile. Mine work without one.
**3. build → test → break → understand → rebuild better.** Every repo is a step up.
**4. Engineering is one problem.** Circuits, code, and cognition — same systems thinking.
